## Weather Telegram Bot 
A Telegram bot for retrieving current weather information for any city. 

# Description 
Weather Telegram Bot allows users to quickly get current weather information through Telegram. The user sends a city name, and the 
bot requests data from an external weather API and returns the current temperature and weather conditions. 

# Features 
- Get current weather information by city name.
- Display current temperature.
- Display weather condition descriptions.
- Handle errors when an invalid city name is provided.
- Asynchronous interaction with an external weather API.

# Technologies 
- ASP.NET Core
- Telegram Bot API
- OpenWeather API
- HttpClient
- Dependency Injection

# Project Goal 
The purpose of this project is to practice working with external APIs, handling HTTP requests, processing JSON data, and developing 
Telegram bots using ASP.NET Core.
